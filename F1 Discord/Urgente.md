| **Ataques de raiders**                                                                                                                     |
| ------------------------------------------------------------------------------------------------------------------------------------------ |
| Un ataque de raiders es cuando un gran número de usuarios o bots se unen a un servidor a la vez con propósitos perturbadores o maliciosos. |
| **Procedimiento**:                                                                                                                         |
| 1. Pausa invitaciones a tu servidor.                                                                                                       |
| 2. **Habilita** [**Modo lento**](https://support.discord.com/hc/en-us/articles/360016150952-Slowmode-Slllooowwwiiinng-down-your-channel)   |
| 3. Reporta el ataque a Discord.                                                                                                            |

| **Estafas**                                                                                                                                                                                                                                                                   |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Consiste en intentar usar las funciones de la plataforma para robar el acceso a cuentas, dinero, datos personales o el control de un servidor de Discord. Los usuarios son el blanco principal porque esperan cierto nivel de confianza dentro de sus comunidades de Discord. |
| **Procedimiento**:                                                                                                                                                                                                                                                            |
| 1. No descargar más archivos de fuentes desconocidas.                                                                                                                                                                                                                         |
| 2. No dar clic en enlaces que sea poco fiables.                                                                                                                                                                                                                               |
| 3. Activar un doble factor de autenticación. Contar con una solución de seguridad en el dispositivo móvil o equipo de cómputo.                                                                                                                                                |





| **Robo de identidad**                                                                                                                                                                            |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Ocurre cuando un tercero malintencionado toma el control de tu cuenta personal o crea una cuenta falsa duplicando tu información (nombre, foto de perfil y biografía) para hacerse pasar por ti. |
| **Procedimiento**:                                                                                                                                                                               |
| 1. [restablecer la contraseña](https://support.discord.com/hc/en-us/articles/218410947-I-forgot-my-Password-Where-can-I-set-a-new-one)                                                           |
| 2. Asegurarte de que la [Autenticación de varios factores](https://support.discord.com/hc/en-us/articles/219576828-Setting-up-Multi-Factor-Authentication) esté activada.                        |
| 3. Es recomendable ejecutar un análisis de Windows Defender, si usas Windows, para detectar posibles virus.                                                                                      |


| **Amenazas**                                                                                                                                                                            |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Una **amenaza en Discord** significa que un usuario ha enviado un mensaje expresando la intención de asesinar o causar un daño físico mortal/verbal/psicologico/digital a otra persona. |
| **Procedimiento**:                                                                                                                                                                      |
| 1. Considera cambiar la cantidad de datos personales que compartes sobre ti mismo.                                                                                                      |
| 2. Considera un enfoque más anónimo.                                                                                                                                                    |
| 3. No hagas clic en ningún enlace o archivo sospechoso.                                                                                                                                 |
